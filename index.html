Install sasAI

安裝 sasAI

The AI assistant for small-angle scattering (SAXS / SANS). Free beta — about 10 minutes to install.

小角度散射（SAXS / SANS）的 AI 助理。免費封測版，安裝約 10 分鐘。

Something went wrong?

Run the installer again — it repairs the installation and keeps your data. Inside sasAI, use Help → Report a Problem…: it sends the team your log automatically.

Uninstall

Windows: Settings → Apps → sasAI → Uninstall. macOS / Linux: delete the sasAI folder (~/Applications/sasAI or ~/.local/share/sasAI) and the sasAI icon on your Desktop.

What sasAI tells the team

Once per version, at the first start: your operating system, CPU, memory, graphics and NPU, and the region and time zone set in the OS — so we know how many testers there are and which computers to support. Never your data files, keys or location beyond that. It is encrypted so only the sasAI team can read it.

出了問題？

再執行一次安裝程式——它會修復安裝，並保留你的資料。在 sasAI 裡可以用 Help → Report a Problem…：它會自動把你的 log 送給團隊。

解除安裝

Windows：設定 → 應用程式 → sasAI → 解除安裝。macOS / Linux：刪除 sasAI 資料夾（~/Applications/sasAI 或 ~/.local/share/sasAI）和桌面上的 sasAI 圖示。

sasAI 會告訴團隊什麼

每個版本第一次啟動時傳一次：你的作業系統、CPU、記憶體、顯示卡和 NPU，以及作業系統裡設定的地區和時區——讓我們知道有多少位測試者、 要支援哪些電腦。絕不會傳你的數據檔、金鑰，或比這更精確的位置。內容有加密，只有 sasAI 團隊能讀。
