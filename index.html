Install sasAI

The AI assistant for small-angle scattering (SAXS / SANS). Free beta — about 10 minutes to install.

  1. Open the file you downloaded

    Click it in your browser's download list. If the browser says the file is not commonly downloaded, choose Keep.

  2. Windows asks first — click “More info”, then “Run anyway”

    sasAI is new, so Windows has not seen it before. This is expected for the beta.

  3. Click “Next”, then “Install”

    Your install code is already filled in. You can keep the suggested folder.

  4. Wait while it sets up (5–15 minutes)

    A window shows the progress while Python and the sasAI components download. Keep the computer online.

  5. Start sasAI from the icon on your desktop

    Click Finish to open it now. Next time, double-click the sasAI icon.

  6. The first time: the offline AI assistant downloads by itself

    You can start working right away. The bottom-right corner shows its progress; when it finishes, the assistant also works offline.

Something went wrong?

Run the installer again — it repairs the installation and keeps your data. Inside sasAI, use Help → Report a problem: it sends the team your log automatically.

Uninstall

Windows: Settings → Apps → sasAI → Uninstall. macOS / Linux: delete the sasAI folder (~/Applications/sasAI or ~/.local/share/sasAI) and the sasAI icon on your Desktop.
